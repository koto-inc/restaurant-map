# 東京グルメショート動画マップ（公開用サイト）

NotionのレストランDBのデータを、独自デザインの公開マップとして見せるための軽量サイトです。
Leaflet + OpenStreetMap（無料・APIキー不要）で動きます。

## 中身
- `index.html` … サイト本体（地図・検索・カテゴリ絞り込み）。データを直接埋め込み済みなので**ダブルクリックで開けます**（サーバ不要）。
- `thumbnails/` … 各店のサムネ画像（TikTokから取得して**恒久保存**済み。署名URLのように失効しません）。
- `data.json` … データの控え（自動同期する場合の元ファイル）。

## ローカルで見る
`index.html` をダブルクリックしてブラウザで開くだけ。
（地図タイルとLeaflet本体の読み込みにインターネット接続が必要です。）

## 無料で一般公開する（いちばん簡単：Netlify Drop）
1. ブラウザで https://app.netlify.com/drop を開く
2. この `restaurant-map` フォルダ**ごと**ドラッグ＆ドロップ
3. 数秒で公開URL（例 `https://○○○.netlify.app`）が発行される → これが一般公開リンク
   - 無料。アカウント登録すると独自ドメインやサイト名変更も可能。

※ Vercel / Cloudflare Pages / GitHub Pages でも同様に無料公開できます。

## データを更新したいとき（手動）
1. `index.html` 内の `const DATA = {...}` に店舗を追記（または `data.json` を更新して同じ内容を反映）
2. その店のサムネ画像を `thumbnails/<slug>.jpg` として追加
3. 再度 Netlify にドラッグ＆ドロップ（同じサイトを上書き）

## 自動同期（Phase 2・任意）
NotionレストランDBの追加を自動でこのサイトに反映したい場合は、
「Notion API でDBを取得 → サムネDLして再ホスト → data.json/HTML再生成 → 自動デプロイ」
というビルドを組めます（Notion連携トークンの発行が必要）。必要になったら構築します。
